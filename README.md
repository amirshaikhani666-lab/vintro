# موقع VINTRO

موقع كتالوج لشركة ألبسة: صفحة رئيسية، قسم صيف ٢٠٢٦، قسم شتاء ٢٠٢٦، وصفحة لكل موديل فيها الألوان والصور والمقاسات وزر طلب عبر واتساب.
الاستضافة مجانية على GitHub Pages، والإضافة والتعديل من لوحة تحكم مجانية (Pages CMS).

---

## صفحات الموقع
الرئيسية · المجموعات · صيف ٢٠٢٦ · شتاء ٢٠٢٦ · صفحة لكل موديل · من نحن · الجملة وطريقة الطلب · تواصل معنا.
نصوص «من نحن» و«ما يميّزنا» و«الأسئلة الشائعة» تتعدّل من «معلومات الشركة» بلوحة التحكم.

## ١. رفع الموقع على GitHub

1. اعمل حساب على github.com إذا ما عندك.
2. اكبس **New repository**، سمّيه مثلاً `my-company-site`، خلّيه **Public**، واكبس **Create repository**.
3. بالصفحة الجديدة اكبس **uploading an existing file**.
4. فك ضغط الملف `site.zip` على جهازك، واسحب **كل الملفات والمجلدات يلي جوّاته** (مش المجلد نفسه) لصفحة الرفع.
   - ملاحظة: الملف `.pages.yml` و `.nojekyll` مخفيين على بعض الأجهزة. على ماك اكبس `Cmd + Shift + .` لتبيّن الملفات المخفية، وعلى ويندوز فعّل «إظهار العناصر المخفية».
5. اكبس **Commit changes**.

## ٢. تشغيل الموقع

1. جوّا المستودع روح على **Settings ← Pages**.
2. تحت **Branch** اختار `main` والمجلد `/ (root)` واكبس **Save**.
3. بعد دقيقة أو دقيقتين بيطلع رابط الموقع فوق، متل: `https://username.github.io/my-company-site/`

## ٣. ربط الدومين

1. اشتري الدومين من أي شركة (Namecheap، GoDaddy، Cloudflare…).
2. بإعدادات الـ DNS عند شركة الدومين ضيف هالسجلات:

   | النوع | الاسم | القيمة |
   |---|---|---|
   | A | @ | 185.199.108.153 |
   | A | @ | 185.199.109.153 |
   | A | @ | 185.199.110.153 |
   | A | @ | 185.199.111.153 |
   | CNAME | www | username.github.io |

   (بدّل `username` باسم حسابك على GitHub)
3. ارجع على **Settings ← Pages**، اكتب الدومين بخانة **Custom domain** (مثلاً `yourcompany.com`) واكبس **Save**.
4. لما يخلص التحقق، فعّل **Enforce HTTPS**. ممكن ياخد من دقائق لكم ساعة.

## ٤. لوحة التحكم: إضافة الموديلات والصور

1. افتح **app.pagescms.org** وفوت بحساب GitHub تبعك.
2. وافق على الصلاحية واختار مستودع الموقع.
3. بيطلعلك قسمين:
   - **الموديلات**: لإضافة موديل جديد أو تعديل موديل.
   - **معلومات الشركة**: الاسم، المؤسس، الأرقام، واتساب، البريد، العنوان، نبذة، وصور غلاف الصيف والشتاء.
4. لكل موديل: اكتب الاسم ورقم الموديل، اختار الموسم، وبقسم **الألوان والصور** ضيف لون واكتب اسمه وارفع صوره. أول صورة بتكون الغلاف.
5. اكبس **Save**، وبعد دقيقة تقريباً بيتحدّث الموقع.

> الموديلات الستة الموجودة هي أمثلة. احذفها أو عدّلها من قسم «الموديلات».

### ألوان بدون كود
إذا ما بتعرف كود اللون، اكتب اسم اللون بس (أسود، أبيض، كحلي، رمادي، زيتي، بيج، خمري، أحمر، أزرق، سماوي، أخضر، بني، كريمي، زهري، أصفر، برتقالي، بنفسجي، رملي، عسلي، فضي، ذهبي) والموقع بيعرف لونه لحاله.

## نصايح للصور

- صورة طولية بنسبة **٤:٥**، مثلاً ١٢٠٠×١٥٠٠ بكسل.
- خلفية سادة وحدة لكل الموديلات، وإضاءة نهارية.
- من ٢ لـ ٤ صور لكل لون: قدّام، ورا، وتفصيلة القماش.
- حجم الصورة أقل من ١ ميغا (استعمل موقع متل squoosh.app للتصغير). الصور الكبيرة بتبطّئ الموقع.
- سمّي الصورة برقم الموديل واللون، مثلاً `s26-101-navy-1.jpg`.

## محتوى الملفات

| الملف | شو فيه |
|---|---|
| `index.html` | الصفحة الرئيسية |
| `summer-2026/` و `winter-2026/` | صفحات المواسم |
| `model/` | صفحة الموديل |
| `data/products.json` | كل الموديلات |
| `data/brand.json` | معلومات الشركة |
| `images/` | الصور |
| `assets/` | التصميم والبرمجة |
| `.pages.yml` | إعدادات لوحة التحكم |

## معاينة الموقع على جهازك
فيك تفتح `index.html` مباشرة من جهازك لتشوف الشكل. بهالحالة بيعرض نسخة الأمثلة المحفوظة بـ `assets/preview-data.js`. الموديلات يلي بتضيفها من لوحة التحكم بتظهر على الموقع المرفوع على GitHub.

## صور الغلاف بالصفحة الرئيسية
الصفحة الرئيسية بتبلّش بقسمين كبار: صيف وشتاء. لما تضيف «صورة غلاف الصيف» و«صورة غلاف الشتاء» من «معلومات الشركة»، بتظهر صورة كاملة بدل الخلفية الكحلي والبيج. الأفضل صورة طولية لموديل لابس من المجموعة، بدقة ١٦٠٠×٢٠٠٠ أو أكبر.
